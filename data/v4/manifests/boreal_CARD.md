# boreal — Boreal Forest Fire: UAV-collected Wildfire Detection and Smoke Segmentation Dataset

## Provenance
- Paper: "Boreal Forest Fire: UAV-collected Wildfire Detection and Smoke Segmentation Dataset",
  Scientific Data (2025), https://www.nature.com/articles/s41597-025-05634-0
  (DOI 10.1038/s41597-025-05634-0).
- Dataset DOI: https://doi.org/10.23729/fd-72c6cf74-b8eb-3687-860d-bf93a1ab94c9
  → Fairdata Etsin record https://etsin.fairdata.fi/dataset/1dce1023-493a-4d63-a906-f2a44f831898
  (Fairdata.fi is the Finnish national research data repository; storage service: IDA).
- Creators: Julius Pesonen, Anna-Maria Raita-Hakola, Teemu Hakala, et al. — Finnish
  Geospatial Research Institute (FGI/NLS) Dept. of Remote Sensing and Photogrammetry +
  University of Jyväskylä Faculty of Information Technology. Publisher/rights holder: FGI.
- Data collected during four prescribed forest-restoration burns in Finland, summer 2022,
  with a DJI Phantom 4 UAV (RGB video, 4K), altitude ~10–200 m AGL, <500 m from the burn,
  camera pitch 0° to −90°. All daylight, dry weather, variable cloud.
- Code (SAM mask generation, training): https://gitlab.com/fgi_nls/public/wildfire-real-time-segmentation
- Published 2025-02-28 (Etsin record created 2025-02-20, modified 2025-08-14).

## Structure and label semantics (audited by opening files — see Audit section)
- `Boreal-Forest-Fire-Subset-A/` — 4,954 still frames (JPG) + YOLO-format bounding-box
  labels (TXT, one file per image, same stem). Frames extracted every 48th frame from the
  drone videos. Folders per burn site: Evo (931), Heinola (906), Karkkila (1096),
  Ruokolahti (1765) + `Empty-Images` (256 reviewed smoke-free negatives with 0-byte label
  files; by filename prefix: Heinola 217, Karkkila 37, Ruokolahti 2).
  - Single class `0` = smoke. NO fire/flame class anywhere in the dataset.
  - 4,862 boxes total; 4,670 images have exactly 1 large box (annotation strategy:
    one big box around the smoke region incl. background); 23 images have 4–12 boxes
    (leftover small-box-strategy annotations); 261 images have 0 boxes.
  - Resolutions: 4096x2160 (3,728), 3840x2160 (1,133; all of Karkkila), 1920x1080
    (93; flights ruokolahti_DJI_0082/0084).
- `Boreal-Forest-Fire-Subset-B/` — 288 MP4 video clips (~30 s each), cut losslessly from
  the original drone recordings. Probed with OpenCV: Evo/Ruokolahti 4096x2160 @ 47.95 fps,
  Karkkila 3840x2160 @ 25 fps, a few Ruokolahti clips 1920x1080 @ 25 fps. Per-video boolean smoke label in
  `Video-Ground-Truth/video-ground-truths.csv` (`Filename;Has Smoke`):
  Evo 31 (all true), Heinola 125 (111 true / 14 false), Karkkila 74 (73/1),
  Ruokolahti 58 (all true). 273 smoke / 15 non-smoke. Video-level labels only —
  NO frame-level annotation in Subset B.
- `Boreal-Forest-Fire-Subset-C/` — 1,472 images (downsampled to 2048x1080 / 1920x1080)
  in train (1184) / valid (248) / test (40) splits + YOLO box labels + binary PNG smoke
  masks. 1,463 of the 1,472 are downsampled re-releases of Subset A frames (same stem);
  9 train images are extra frames not in A and carry NO labels or masks (verified by eye:
  they DO contain smoke — unlabeled positives).
  - `sam_masks/` (1,417): masks generated by Segment Anything Model prompted with the
    human box → MODEL-ASSISTED origin.
  - `manual_masks/test` (40): hand-drawn masks (test set) → human origin.
  - 47 images have empty label files; 46 are negatives matching Subset A empties, but
    `train/evoDJI_0001_frame23` (the same frame missing its box in Subset A) has an empty
    box-label yet a valid SAM mask covering its smoke (~14% of pixels) — in the manifest
    it is a mask-positive with n_smoke_boxes=0. Every boxed positive has a mask; no boxed
    positives are missing masks.
- `Visualisation-And-Coordinate-Conversion-Notebook/` — helper Jupyter notebook.

## Counts
- Unique still images: 4,963 underlying frames (4,954 in Subset A + 9 extra unlabeled in
  Subset C train). The other 1,463 Subset C files are downsampled duplicates of Subset A
  frames — do NOT count them twice and never split A/C copies of the same frame across
  train/eval.
- Videos: 288 clips (~2.4 h total).
- Independent units (parent_unit): 4 burn events/sites — burn_evo (2022-05-24),
  burn_heinola (2022-06-28), burn_karkkila (2022-07-06), burn_ruokolahti (2022-08-15).
  All frames/clips within a site are the SAME burn on the SAME day; adjacent frames are
  1–2 s apart and highly correlated. v4 aerial splits must group by burn site.
- Sub-unit granularity: 31 original DJI recordings (camera_or_flight_id), evo 3,
  heinola 9, karkkila 10, ruokolahti 9. Subset B clip names (evo_1…) cannot be mapped
  back to DJI recording ids.
- Manifest rows: 6,714 (4,954 A images + 1,472 C images + 288 B videos).

## Label completeness / honesty notes
- Only SMOKE is annotated. Flames are clearly visible in many positive frames (e.g.
  ruokolahti_DJI_0086_frame294, ruokolahti_DJI_0087_*) but carry NO fire label;
  has_fire_label=False everywhere means "no fire annotation", not "no fire visible".
- 5 Subset A images in the annotated site folders have EMPTY label files despite clearly
  visible smoke (verified by eye): evoDJI_0001_frame23, karkkila_DJI_0004_frame132,
  ruokolahti_DJI_0087_frame46/249/259. Marked label_type='none', origin='unknown' in the
  manifest — NEVER use as negatives.
- The 9 extra Subset C train images (evoDJI_0001_frame216–220,
  ruokolahti_DJI_0087_frame62–65) are unlabeled positives (smoke visible, no label/mask);
  marked label_type='none'.
- The 256 Empty-Images negatives were sampled (8 viewed): genuinely smoke-free aerial
  forest — usable as verified negatives.
- Subset B video labels are boolean per 30-s clip; authors state these labels were
  double-checked but never validated for model training. A "false" clip means no smoke
  anywhere in the clip; a "true" clip has smoke in an unknown subset of frames.
- Boxes are the "large box" strategy — a single box enclosing the smoke region including
  background; not tight instance boxes. A few images retain the multi-small-box style.
- SAM masks are model-assisted; visual audit found generally good plume coverage but
  occasional bleed into sky/background (e.g. heinola_DJI_0033_frame37) and
  under-segmentation of thin smoke edges.

## Viewpoint / domain
- Genuine UAV aerial viewpoint over boreal forest (Norway spruce, Scots pine, birch),
  oblique to nadir, close range to ~500 m standoff. Smoke plumes from ground fires;
  white/grey plumes of highly variable size (from wisps to plumes filling half the frame).

## Confounders present
- Clouds/hazy sky directly behind and around plumes (Evo frames show smoke against
  cloudy sky); lakes with sun glint; clearcut areas with bare ground; gravel roads;
  people/vehicles were removed by the authors for GDPR.
- Negatives contain lakes, clearcuts, roads — good hard negatives for aerial
  false-positive suppression, but only 256 labeled negative frames + 15 negative clips:
  the dataset is heavily positive-skewed (4,693 of 4,949 labeled Subset A frames = 94.8%
  have smoke).
- Per-site look is very homogeneous (one day, one weather, one camera) — expect strong
  site memorization if splits are not grouped by burn.

## Contamination vs existing sources
- Filename overlap vs pyro-sdis / D-Fire / FIgLib manifests: 0 of 6,668 boreal basenames
  (existing manifests have no sha256 column, so no hash check was possible cheaply).
- Provenance argues near-zero risk: private FGI drone footage from Finland 2022, first
  published 2025-02; pyro-sdis/FIgLib are fixed tower cameras (France/California),
  D-Fire predates this release. Full near-dup pass deferred to the central pipeline.

## Blockers
- None. Open access, no registration, stable API, all checksums verified.

## Manifest
- `/local/home/tianrgua/cvproject/data/v4/manifests/boreal_manifest.parquet`
- parent_unit = burn_<site> (4 values) — grouped-split key.
- camera_or_flight_id = <site>_DJI_<recording#> for images; null for Subset B clips.
- timestamp = burn date (per site); intra-day time not recoverable from filenames.
- label_type: box (Subset A + boxed-only C rows), mask (Subset C rows with masks),
  videolabel (Subset B), none (unlabeled/missed-annotation rows).
- origin: original-human (boxes, manual masks, video labels), model-assisted (SAM masks),
  unknown (unlabeled).
- Videos were NOT frame-extracted: frame-level labels already exist in Subsets A/C
  (which were sampled from these same videos); extracting more frames would only add
  near-duplicates of already-labeled material. The 15 non-smoke clips can be mined for
  negative frames later if needed.
